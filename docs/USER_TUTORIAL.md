## 1. 这是什么

**WEB 文字修仙模拟器** 是一款修真题材的**人生模拟器**：

- **一局 = 一段修行人生**。从练气开始，一直走到飞升，或中途坐化
- **每回合 = 一个关键抉择**。每回合推进一段修行岁月
- **每次抉择只有 4 个选项**：`A 稳妥 / B 机遇 / C 风险 / D 气运`，**没有自由文本输入**
- **没有 HP / MP 数值**，没有战斗血条；斗法、禁地、心魔、天劫都以"事件判定"方式表达
- **核心是规则引擎推进人生**，玩家做关键抉择，大模型只负责短文本润色与选项文案

如果想看"为什么是这样设计"，请读 [GAME_MODE_SPEC.md](GAME_MODE_SPEC.md)。

## 3. 访客 vs 账号

进入游戏前先选身份：

### 3.1 访客（推荐先试玩）

- **不需要注册**，直接点首页"新游戏"即可
- 服务器会给浏览器发一个 `HttpOnly` 访客 cookie（看不到、无法被前端脚本读取，安全性高）
- 可以正常游玩全部回合、推进境界、看终局摘要
- **缺点**：
  - **不能云端存档**（关浏览器 = 进度消失；进程内存态）
  - **没有 5 个存档槽**功能
  - **不能累计飞升次数**（影响稀有度解锁）

### 3.2 邀请码账号

- 点首页"邀请码注册"，填：
  - 用户名（2-40 字）
  - 密码（至少 8 位）
  - 邀请码（向群主索取）
- 注册成功后服务器发 `HttpOnly` 会话 cookie，**登录态保持 14 天**
- **优点**：
  - **5 档云端存档**（`slot_1..slot_5`），可以读档
  - 可以消费**跨局"传承奖励"**（上局成就解锁的额外属性点 / 天赋 / 寿元）
  - 飞升次数会写入账号，影响稀有度解锁

### 3.3 简单对比

| 操作 | 访客 | 账号 |
| --- | --- | --- |
| 进入游戏 | ✅ | ✅ |
| 玩到飞升 / 死亡 | ✅ | ✅ |
| 云端存档 / 读档 | ❌ | ✅（5 档） |
| 飞升次数累计 | ❌ | ✅（影响稀有度） |
| 跨局传承奖励 | ❌ | ✅ |

如果只是想试试玩法，建议先访客开一局；想长期玩就注册账号。

## 4. 创建角色

点首页"新游戏"后，进入角色创建页。

### 4.1 选模式

页面顶部有三个模式入口：

- **游戏模式**（高亮可点）— 当前主线
- **引导模式**（灰）— 暂不开放
- **小说模式**（灰）— 暂不开发

直接进入"游戏模式"。

### 4.2 选生成方式

- **自行选择**：自己填每一项（推荐新手）
- **随机生成**：一键随机天赋 / 灵根 / 家世 / 属性（推荐想快速开局的玩家）

### 4.3 自行选择 — 各项说明

| 项目 | 说明 | 可选项 |
| --- | --- | --- |
| **游戏名称** | 你给这个世界的名字，会影响开篇叙事 | 任意文字 |
| **角色名** | 你的道号 | 任意文字 |
| **天赋** | 命中资质 | 平平无奇 / 草木亲和 / 剑心微明 / 惊雷骨（+ 通关解锁更高稀有度） |
| **灵根** | 修真根骨 | 金 / 木 / 水 / 火 / 土 / 冰 / 雷 / 风（+ 通关解锁阴阳灵根 / 混沌灵根） |
| **家世** | 出身背景 | 农家 / 寒门 / 小族 / 宗门旁支（+ 通关解锁隐世仙族） |
| **难度** | 影响数值节奏 | 简单 / 普通 / 困难 |

> 通关一定次数或飞升后会解锁更高稀有度的天赋 / 灵根 / 家世，让下一局有更丰富的开局。

### 4.4 自行选择 — 六维属性

六维属性共 **300 点预算**，每项下限 20、上限 80：

| 属性 | 作用 |
| --- | --- |
| **根骨** | 肉身筋骨，决定能承载多重的灵气 |
| **悟性** | 理解功法和天地法则的速度，影响经验获取 |
| **气运** | 机缘与风险偏移，**D 选项尤其依赖此项** |
| **心性** | 定力与抗走火入魔 |
| **体魄** | 身体强韧，影响受伤阈值 |
| **神魂** | 精神强度，影响幻境、心魔、对峙 |

**小贴士**：

- 高气运 → D 选项回报显著提升
- 高悟性 → 加快破境节奏
- 想稳就重点加心性、体魄；想快就重点加悟性、气运

### 4.5 随机生成

一键随机填齐天赋 / 灵根 / 家世，每项属性随机分配（每项 18-99 随机，可能超出预算上限）。完全靠运气。

### 4.6 彩蛋

游戏名称填 **`2917`** 会触发**隐藏开局**：

- 角色名：**阿清**
- 全属性 99
- 金币 9999

这是给老玩家的致敬，UI 上没有任何提示。填错了不知道没关系，发现了就是缘分。

- 顶部：叙事卡片滚动区（最近 80 条）
- 中部：当前回合 **4 个固定选项按钮**
- 底部：**底部条幅**（仅在模型不可用时出现"本地故事兜底"提示）

## 6. A / B / C / D 选项详解

**这是游戏核心**。每回合从 4 选 1。

### 6.1 A 稳妥

- **效果**：低风险推进，经验和属性变化温和，年限推进较短
- **典型动作**：闭关、温养法宝、稳固境界、打理洞府
- **风险档位**：低
- **适合**：保守玩家、新手、保命

### 6.2 B 机遇

- **效果**：中风险中收益，可能触发支线事件与机缘
- **典型动作**：拜访前辈、参加法会、寻访遗迹、结交同道
- **风险档位**：中
- **适合**：想要丰富剧情的玩家

### 6.3 C 风险

- **效果**：高风险高收益，**年限推进最长**，但有**约 5% 概率直接死亡**
- **典型动作**：强行破境、闯禁地、夺机缘、迎战仇敌
- **风险档位**：高
- **适合**：激进玩家、追求极限收益

### 6.4 D 气运

- **效果**：强绑定气运属性，结果上下限都很大
- **典型动作**：顺心而行、听天由命、追随预感、赌因果
- **风险档位**：浮动（高气运 → 高回报；低气运 → 可能命运反噬）
- **适合**：信任命运的老玩家；气运属性高的角色

### 6.5 常见误区

- **D 不是自由文本输入框**。它是 4 个固定选项中的第 4 个
- 点击之后由系统结算，不是写自定义文本
- 模型不可用时 D 仍然可选，落到本地故事兜底节点
- 如果看不到 4 个按钮，说明模型卡了，按"本地故事兜底"提示操作即可

## 7. 境界、寿元与时间

### 7.1 9 阶境界

境界从低到高固定 9 阶：

```
练气 → 筑基 → 金丹 → 元婴 → 化神 → 合体 → 大乘 → 渡劫 → 飞升
```

当前已完整实现前 5 阶；合体、大乘、渡劫、飞升保留规则数据，持续打磨中。

### 7.2 各境界寿元上限

寿元耗尽则"坐化"（终局）：

| 境界 | 寿元上限 | 境界 | 寿元上限 |
| --- | --- | --- | --- |
| 练气 | 100 | 化神 | 2000 |
| 筑基 | 200 | 合体 | 4000 |
| 金丹 | 500 | 大乘 | 5000 |
| 元婴 | 1000 | 渡劫 | 6000 |
| | | 飞升 | 9999 |

### 7.3 小层推进 vs 大境界突破

每个境界又有"小层"（如练气 1-9 层）。**小层满了经验自动升层**，无风险。

**大境界突破**需要满足：

1. 经验达标
2. 悟性达标
3. 突破材料齐备
4. 成功率（基础 80% → 5% 递减；天灵根 +10%、地灵根 +5%）

**破境失败的代价**：经验 -20，并附加"走火入魔"状态若干回合。

**破境到飞升**：本局直接结束，称为"飞升结局"。

## 8. 终局与奖励

### 8.1 三种结束方式

1. **飞升**：完成 9 阶突破，触发"飞升成仙"结局（最高成就）
2. **坐化 / 死亡**：寿元耗尽、遭遇致命事件、走火入魔身死等
3. **手动结束**：点"结束本局"按钮

### 8.2 终局摘要

终局时系统给出：

- **死因分类**：飞升 > 因果反噬 > 事件 > 寿元 > 手动
- **成就列表**：按境界、回合、库存、功法、寿元评估
- **奖励列表**：属性点 / 传承天赋 / 开局称号 / 额外寿元

### 8.3 奖励是否累计？

- **注册账号局**：成就与奖励会写入你的账号云端；下次开局时"传承奖励"会作为下一局的起始加成
- **访客局**：成就在终局页能看到，但关浏览器即丢失

## 9. 存档与读档（仅账号）

点顶栏"存档"按钮 → 弹窗"存档"标签 → 5 个槽位 `slot_1..slot_5`：

- **空槽**：可"保存到此档"
- **已存**：显示角色名 / 境界 / 回合 / 更新时间；可"读档"或"覆盖保存"

读档后：

- 游戏从该存档的回合继续
- 已读档自动切到主界面（如果存档已经终局，会切到终局页）

**访客无此功能**。

## 10. 设置（仅管理员）

普通用户看不到模型配置页。

**管理员**：点顶栏"设置"按钮 → "设置"标签：

- 4 个预设：**Agens** / **DeepSeek** / **Qwen** / **GLM**
- 自定义填：provider / base_url / model / api_key
- API key 在前端输入后保存到后端 DB（**脱敏显示**），**不会回传前端**；下次提交清空输入框

## 11. 模型不可用怎么办

游戏期间如果后端无法调用 LLM（例如 key 失效、网络问题、配额耗尽）：

- 顶部条幅出现 **"模型暂不可用，当前以本地故事继续"**
- 可选 **"继续本局"**（用预设的本地故事节点继续推进）或 **"结束本局"**
- 本地故事是纯规则引擎产物，叙事较短但能完整结算回合
- 不影响存档 / 读档 / 终局机制

## 12. 常见问题

**Q：能输入自定义文本吗？**

A：不能。当前 v5 已切到 A/B/C/D 固定语义，没有自由输入框。"继续本局"等兜底按钮走的是专用 API，不是自由文本。

**Q：进度会不会丢？**

A：访客局：会（关浏览器 = 丢；进程内存态）。账号局：不会，存到 5 档云端。

**Q：游戏卡住了怎么办？**

A：刷新页面（访客进度会丢）；如果是模型问题，按"本地故事"提示操作即可。

**Q：怎么快速解锁稀有天赋？**

A：完成 1 局解锁紫色天赋；飞升 1 次解锁橙色天赋；飞升 2 次解锁红色天赋。随机模式不看 unlock，但手动模式受限。

**Q：2917 之类的彩蛋？**

A：游戏名填 `2917` 触发隐藏开局"阿清"。其它彩蛋未公开。

**Q：可以邀请朋友吗？**

A：邀请码可向 QQ 群 `985776771` 群主索取。普通邀请码是单次使用。

**Q：BGM 不响？**

A：浏览器禁止无手势自动播放。第一次点扬声器按钮后才能开始播放。音量固定 0.42。

**Q：可以多设备同时登录吗？**

A：可以。账号 cookie 在每个浏览器独立；不同设备互不干扰。

**Q：账号被封 / 忘记密码？**

A：当前为 Alpha 阶段，账号相关问题请联系 QQ 群群主。
