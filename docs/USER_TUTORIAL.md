## 1. 这是什么

文字修仙模拟器是一款修真题材的人生模拟游戏：

- 一局是一段修行人生，从练气起步，可能飞升，也可能坐化或遭遇意外。
- 每回合是一次关键抉择，不固定等于一年；时间流逝由境界、行动和事件决定。
- 每回合只有四个按钮：`A 稳妥 / B 机遇 / C 风险 / D 气运`。
- 没有自由文本输入，没有 HP/MP、经验、感悟、灵石面板。
- 斗法、禁地、心魔、天劫以事件判定表达，不做回合制战斗条。
- 当前主界面采用编年史形式记录："某历某年，你在某地作出选择，因果如何推进"。

## 3. 访客与账号

**访客局**

- 不需要注册，点"新游戏"即可玩。
- 可以完成一整局、看终局摘要。
- 不能使用云存档槽；访客局会短期保留，默认 24 小时后过期。
- 不累计账号飞升次数和跨局奖励。
- 在访客局中登录或注册后，当前访客局会被删除，不迁移进账号。

**账号局**

- 使用用户名、密码和邀请码注册。
- 登录后有 5 个云存档槽：`slot_1` 到 `slot_5`。
- 可以保存、读档、累计飞升次数，并在后续版本使用死亡奖励/传承奖励。

## 4. 创建角色

角色创建页只保留当前游戏模式需要的内容：

- **角色名**：你的道号或名字。
- **天赋**：影响开局倾向和部分事件判定。
- **灵根**：影响突破、修炼和机缘倾向。
- **家世**：决定出生背景、开场资源和风险。
- **难度**：影响时间、风险和收益节奏。
- **六维属性**：体魄、神魂、气运、悟性、心性、根骨。

手选时只展示当前已解锁颜色；随机可以抽到更高颜色内容。天赋、灵根、家世统一以颜色体系表达：白、绿、蓝、紫、橙、红。

## 5. 六维属性

| 属性 | 主要影响 |
| --- | --- |
| 体魄 | 伤势、斗法、禁地承受力 |
| 神魂 | 心魔、幻境、神识类事件 |
| 气运 | D 气运选项、机缘上限和反噬风险 |
| 悟性 | 理解功法、参悟事件、部分突破准备 |
| 心性 | 走火入魔、长期闭关、逆境稳定性 |
| 根骨 | 修炼根基、承载灵气、突破基础 |

第一版尽量避免复杂派生数值，每项只影响少量核心判定。

当前属性显示和结算都使用 0-10 尺度，5 代表普通均衡。角色创建时手动分配总和固定为 30；随机开局也固定总和 30，但单项可以到 0 或 10。

## 6. 游戏主界面

主界面由两部分组成：

- **角色摘要**：年龄、境界、剩余寿元/寿元上限、灵根、天赋、家世、气运。
- **编年史日志**：按年龄记录关键人生节点，并在底部给出 A/B/C/D 四个选项。

示例：

```text
玄历元年，你出生在青溪村许家，被起名为许满。
玄历十年，你初见山门雾气，接引弟子问你要走哪条路。

A 稳妥  按山门规矩登记入门
B 机遇  询问外门近况，寻找第一桩机缘
C 风险  绕到山门侧径探查雾气来源
D 气运  随缘听钟声指向，不刻意争抢名额
```

## 7. A/B/C/D

- **A 稳妥**：闭关、修炼、整顿、低风险。
- **B 机遇**：外出、结交、寻访、探索，中风险。
- **C 风险**：突破、斗法、禁地、豪赌，高风险。
- **D 气运**：随缘、天命、未知机缘，强绑定气运；可能逆天改命，也可能命运反噬。

D 是固定选项，不是自由输入框。按钮文案会随场景变化，但语义始终是气运/天命路径。

## 8. 时间、寿元与终局

- 每回合推进一段修行岁月。
- 低境界可能推进 1-3 年；高境界可能推进十年、百年甚至更久。
- UI 显示年龄、剩余寿元和寿元上限。例如练气寿元 100、年龄 18 时显示 `82/100`。
- 年龄达到寿元上限且未突破或飞升，会进入寿终/坐化结局。
- 飞升、事件死亡、寿元耗尽和手动结束都会进入终局页。

## 9. 存档

只有账号用户可以云存档：

- 空档位显示"保存到此档"。
- 已有档位显示"读档"和"覆盖保存"。
- 读档后会回到对应局面；如果存档已经终局，会进入终局页。

访客局没有云存档服务。

## 10. 记录暂未续上

如果模型暂不可用或本回合结构不完整，系统会保留当前局面并显示脱敏提示：

> 本回合叙事暂不可用，请选择重试、转入本地故事或结束本局。

选择“重试”不会重新结算规则；选择“转入本地故事”后才会显示本地 A/B/C/D 选项；也可以使用“结束本局”进入终局流程。

前端不会显示 API Key、数据库错误、模型供应商内部报错或技术堆栈。

## 11. 常见问题

**Q：不登录能玩吗？**

A：能。点"新游戏"即可访客游玩，只是不能云存档。

**Q：能输入自定义行动吗？**

A：不能。当前 v5 是 A/B/C/D 固定语义。

**Q：为什么点选项后要等一会？**

A：普通回合由规则引擎先结算，再让模型润色短编年史文本。高风险事件、突破、死亡或异常状态会额外触发 Judge 审核，所以会更慢。

**Q：BGM 不响？**

A：浏览器禁止无手势自动播放。第一次点右上角扬声器后才会开始播放。
